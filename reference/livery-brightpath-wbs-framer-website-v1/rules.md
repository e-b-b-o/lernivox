# brightpath-wbs.framer.website: design rules

A light interface on a near-white neutral background where a dark indigo accent marks the next step. Type is Bricolage Grotesque set tight at large sizes, corners are 10px, and depth comes from soft neutral shadows.

## Principles

### Soft, neutral depth

Lift raised elements with the measured shadow (rgb(27, 52, 40) 0px 4px 0px 0px).

_Why:_ Shadows appear on about 2% of elements; they mark what floats above the page.

### Big type, quiet body

Pair 82px headings in Bricolage Grotesque with 16px body text in Instrument Sans.

_Why:_ A 5.1× jump between headline and body creates strong hierarchy with few elements.

### Consistent corners

Use 10px corners as the default radius.

_Why:_ It is the most common measured radius; one radius family is what makes separate components feel like one product.

## Never

- **Never use positive letter-spacing on headings.** Large type is tightened, down to -0.08em on the biggest sizes.
- **Never set button labels in all capitals.** No measured button uses uppercase text.
- **Never add decoration the measurements don't show.** The kit records what the site does; additions (gradients, glows, textures) are where a copy stops resembling it.

## Colour

- Light theme: near-white neutral background (#f4f0e5) with #eae4d3 surfaces.
- Body text #000000 on the background reads at 18.4:1; secondary text uses #45564b.
- Accent #0000ee (dark indigo) with #ffffff text on top of it.

## Typography

- Bricolage Grotesque for headings, Instrument Sans for body.
- Scale: display 82px, h1 50px, h2 40px, h3 32px, h4 30px, h5 24px, h6 22px.
- Weights in use: 400, 500.
- Headings are tightened (-0.08em at 82px); body text keeps normal tracking.

## Shape and depth

- Radii: 2px (7%), 4px (3%), 9px (3%), 10px (31%), 20px (26%), 50px (7%), 100px (14%), pill (6%).
- Borders: none in the border tone.
- Shadows: rgb(27, 52, 40) 0px 4px 0px 0px | rgb(178, 110, 69) 0px 4px 0px 0px | rgb(84, 136, 178) 3px 3px 0px 0px.
