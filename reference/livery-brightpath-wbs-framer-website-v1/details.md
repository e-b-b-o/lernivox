# Details

The small things that make this site feel finished. People notice them without naming them; apply the ones that fit your project.

- **Frosted glass**: 4 surfaces blur what's behind them (backdrop-filter), usually headers, menus and overlays.
- **OpenType features**: The type uses OpenType features: character variants cv03, cv04, cv09, cv11. Turn on the same ones (font-feature-settings / font-variant-numeric) where the font supports them.
- **Balanced line breaks**: Headings and paragraphs wrap evenly (text-wrap: balance / pretty) on 80 elements: no lonely last words.
- **Considered underlines**: Links set their own underline offset rather than the browser default.
- **Shaped edges and fades**: 4 masks cut or fade edges instead of hard rectangles.
- **Styled scrollbars**: Scrollbars are restyled to match the interface.
